Run it yourself

从自己的来源开始。

  1. 准备 Docker 与 API 凭据启动 Docker Desktop，从 my.telegram.org 获取 api_id 和 api_hash。
  2. 在终端完成首次登录运行右侧命令，按提示输入手机号、验证码与已启用的两步验证密码。
  3. 打开链接，选择频道启动脚本会输出访问链接。在阅读器的「频道」中勾选来源，等待首次同步。

开始之前，你可能想知道。

“在线转发”具体是什么？

你的本机服务通过 Telegram API 按需读取图片或视频分块，再通过 HTTP 转发到 Web 浏览器播放。应用保存帖子索引与偏好状态，媒体使用有上限的内存缓存。

手机和平板怎么使用？

与电脑连接同一 Wi-Fi，打开启动脚本提供的完整局域网链接，或在电脑阅读器点击「手机」扫码。电脑需要保持开机、联网；访问口令只供自己的设备使用。

系统如何学习偏好？

将频道、标签、正文词、媒体类型和时长等特征及其组合，与喜欢、隐藏、停留等反馈关联，在本地更新权重。「口味」面板可查看已学习的特征。默认无需 GPU 或外部模型 API。

预载 200 条会占用很多空间吗？

200 条是待刷卡片索引。前方 4 条媒体提前准备，服务端图片缓存最多约 200 MiB，视频分块缓存最多约 600 MiB。应用不主动归档完整媒体文件；浏览器与操作系统仍可能管理缓存或交换内存。

网络不稳或者触发请求限制怎么办？

内容流保留待播任务，显示冷却倒计时并自动重试。实际播放取决于网络、缓存与源内容可用性。当前版本面向个人本机与受信任局域网使用。
